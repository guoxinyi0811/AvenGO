怎么排一周 · 不用钉死星期几

力量之间隔一天,顺序轮着来,下肢多一点:

A有氧B有氧A
B有氧A有氧B

下一周首字母接着换,长期就是 A 比 B 略多——这是故意的,臀腿是最大的血糖处置器官。

有氧日:湖滨快走或 Bike Share 骑行 30–40 分钟,心率 ~120(能说话但不能唱歌)。热浪/雷雨 → PATH 快走或室内泳池。

每天:饭后走 10–15 分钟。这条性价比最高,门槛几乎为零。

最低完成线:任何一天,做到以下之一就算达标——一次力量、一次20分钟骑行、或三次饭后散步。

什么时候加量 · 怎么加

升级信号:3 组都做到次数上限,且最后一组还剩 2–3 下没用尽 → 下次可以加。不用每周硬加,身体准备好了再加。

加的顺序(从易到难):

  • 加重量 +2–5lb(哑铃到顶 20lb 前优先这条)
  • 加次数 → 加组数
  • 放慢离心:下放用 3–4 秒(几乎不加重就显著变难,对血糖处理特别有效)
  • 顶峰停顿 2 秒(臀桥尤其)
  • 减少支撑面:双腿 → 单腿(哑铃 20lb 到顶后的主要出路)

降级信号:动作变形(脚跟翘、膝内扣、弓背、塌腰)→ 立刻退回上一档。宁可轻一点做对。

出现尖锐疼痛(不是肌肉酸胀)→ 停下,记下来告诉我。这类信号不要忍。

器械替换 · 你家里没有的那些
  • 壶铃硬拉 → 双手各持哑铃做罗马尼亚硬拉,发力模式一样
  • 坐姿器械划船 → 拉力带坐姿划船(脚蹬带子)
  • 楔形板 → 平地做就行,不影响效果;想要斜面可用瑜伽砖或一本厚书垫脚跟
  • 跪姿俯卧撑 → 优先上斜俯卧撑(手扶桌沿/台面),更容易保持核心不塌腰
追踪什么 · 别每天称体重
  • 每 2 周同条件称重(晨起空腹如厕后)——看趋势不看单点
  • 每 4–6 周量腰围——比体重更能反映内脏脂肪
  • 每天打个勾就行:吃了吗 / 动了吗 / 餐后犯困吗
  • 3 个月复测 InBody + 空腹胰岛素 / HOMA-IR / 甘油三酯

预期:体重降 5% 左右,HOMA-IR 通常就能看到明显改善,甘油三酯降得更快。不用瘦很多才能看到代谢好转。
